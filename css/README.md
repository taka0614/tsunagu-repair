# CSS の構成

`index.html` で上から順に読み込みます（後のファイルほど優先）。

| ファイル | 内容 |
|---|---|
| base.css | 色・書体・動きの変数／ナイトモード／文字サイズ／共通要素／ボタン／ロゴ |
| layout.css | 分割レイアウト／左パネル（写真・canvas・進捗ナビ）／ヘッダー／メニュー／スマホ用ドック |
| sections.css | セクション共通／hero〜contact の各セクション／フッター |
| motion.css | 読み込み・スクロール・左パネルの切替の動き |

- 色を変えるときは `base.css` の先頭（変数）だけを編集します。
- 各ファイルの先頭に目次があります。
- スマホ用の指定は、各ブロックの最後の `@media (max-width: 860px)` にあります。
